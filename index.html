Jarvis

Asistente personal de voz con inteligencia artificial

Asistente para Windows que entiende lenguaje natural y ejecuta acciones reales. Le hablas y un modelo de IA decide qué herramientas usar para controlar el PC, un teléfono Android y Alexa.

  • Palabra clave ("Hey Jarvis") y transcripción de voz locales, sin internet, con aceleración por GPU.
  • Cerebro con la API de Claude y tool use: hasta 8 acciones encadenadas por petición. Gemini como alternativa.
  • Control remoto vía Telegram, rutinas programables en YAML, memoria y recordatorios.
  • Seguridad: API solo local, usuarios autorizados y confirmación para acciones sensibles.
  • Servicio que arranca con Windows y se reinicia solo ante fallas.

VeloTrack

Plataforma de rastreo GPS de vehículos · App Android y web

Plataforma para seguir una flota de vehículos en tiempo real, revisar recorridos y recibir alertas en el celular.

  • Mapa en tiempo real con Server-Sent Events, sin recargar la app.
  • Historial de rutas con reproducción y colores por velocidad.
  • Geozonas dibujadas en el mapa y alertas push por exceso de velocidad, entrada/salida de zonas y encendido.
  • Reportes por período exportables a CSV.
  • API REST con autenticación por token, inicio de sesión con Google y PostgreSQL en la nube.
