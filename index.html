Jarvis

Asistente personal de voz con IA

Le hablas y un modelo de IA decide qué herramientas usar para controlar el PC, un teléfono Android y Alexa.

  • Cerebro con la API de Claude y tool use: hasta 8 acciones encadenadas por petición.
  • Control por Telegram, rutinas en YAML, memoria y recordatorios.
  • Seguridad: API solo local, usuarios autorizados y confirmación de acciones sensibles.

VeloTrack

Plataforma de rastreo GPS de vehículos

App Android y web para seguir una flota en tiempo real, revisar recorridos y recibir alertas en el celular.

  • Mapa en tiempo real con Server-Sent Events, sin recargar la app.
  • Historial de rutas con reproducción y colores por velocidad.
  • Geozonas y alertas push por velocidad, zonas y encendido.
  • Reportes exportables a CSV, API REST con token y login con Google.
